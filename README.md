# dsh-kuakua · 一键夸夸

给 DeepSeek Harness 的输入栏加两枚按钮：**一键夸夸** 和 **表情包**。

- **夸夸**：按你的表达式（或整句模板）拼一句夸夸，带上动作描写，放进输入框。图标 + 文字。
- **表情包**：弹一个四行的表情面板，点一张图就作为附件进输入框；支持置顶、删除、从 QQ 导入、把对话里的图收进来。

按钮放在「工作区内修改」右边那排，尺寸、颜色、字号都跟宿主那排图标对齐；悬停有淡底、细边框和一点投影。

## 装

```bash
dsh plugin --profile desktop add /path/to/dsh-kuakua
```

本地开发可以直接指向目录（会 link 进去）：

```bash
dsh plugin --profile desktop add ~/projects/dsh-kuakua
```

装完刷新页面：输入栏多出「夸夸」和表情包图标，侧栏左上角多一行「一键夸夸」，设置里多一页。

## 用

### 夸夸

点一下，按下面的规则拼一句，**只放进输入框，不自动发送**。

五张词表各随机取一个：

| 变量 | 例子 |
| --- | --- |
| `{称呼}` | 你自己填的称呼（默认空） |
| `{夸奖}` | 这活干得漂亮 / 写得真清楚 |
| `{动作}` | 你自己填的动作（默认空） |
| `{颜文字}` | (๑•̀ㅂ•́)و✧ |
| `{emoji}` | ✨ |

表达式自己排，比如：

```
{称呼}{夸奖}（{动作}）{颜文字}{emoji}
```

哪张表是空的，那一段整段消失，不会留个空括号。也可以切到「整句模板」模式，直接从写好的整句里挑一句。

**连点夸夸时**（设置里可选）：

- **继续加一条**（默认）：每点一次追加一行
- **换掉上一条**：只替换上一次按钮插进去的那句，你自己打的字一个字不动；手动改过那句或已经发出去，就退回追加

### 表情包

- 面板固定在输入框上方、贴着输入框，默认 **四行**，多的在里面滚动
- 点一张 → 图片作为附件进输入框（不自动发）；超过 4MB 或递不进去时只提示，不往输入框里塞文件名
- **右键**一张：置顶 / 取消置顶、删除（删除不弹确认，面板不关、滚动位置不动）
- 排序：置顶的在前，其余按修改时间 **新的在前**
- 图来自一个文件夹，默认 `~/.dsh/kuakua/stickers`（插件自己建），也可以在设置里指到任意目录

### 把对话里的图收进表情包

在对话里的任意图片上右键 →「添加到表情包」。会把图取下来、按真实文件头判断格式、存成 `chat_<时间戳>.<真实扩展名>`，立刻出现在面板最前面。

只对能取到内容的图有效（本地路由、blob 都行）；跨域外链读不到。单张上限 8MB。

### 从 QQ 导入

设置页「从 QQ 导入」，**只读** QQ 的表情目录、**复制**进当前表情文件夹，导入这一步要自己点：

- **macOS**：`~/Library/Containers/com.tencent.qq/…/nt_data/Emoji/personal_emoji/Ori`
- **Windows**：`Documents/Tencent Files/<QQ号>/nt_qq/nt_data/Emoji/personal_emoji/Ori`

自动扫不到（Windows 上 QQ 装在别的盘很常见）就手填目录再扫。勾选来源 → 导入，会在下面显示前 24 张缩略图预览。

QQ 那边有些文件扩展名是 `.gif` 其实内容是 PNG，导入时按**文件头**判断真实格式再改名，不然面板里显示不出来。同名同大小自动跳过，重复点不会灌一堆。

微信的表情包是加密的（读出来是乱码，不是图片），暂不支持。

## 数据放哪

```
~/.dsh/kuakua/
├── config.json     # 所有设置（称呼、词表、表达式、置顶清单…）
└── stickers/       # 默认表情目录
```

配置是明文 JSON，坏字段会被忽略，不会把页面搞崩。

## 这个插件不干什么

- 不发消息，只往输入框里放东西
- 不碰别的插件的图库（dsh-meme 有它自己的一套）
- 除本机 `/x-kuakua` 路由外没有外部请求；写配置和删除只接受本机回环地址

## 已知限制

- 附图走的是输入栏自己的粘贴通道（插件拿不到它内部的 `addFiles`）。正在跑一轮的时候输入栏不收附件，面板会说明。
- 表情目录**只扫一层**，子文件夹里的图不认。
- 称呼、动作两张表**默认空着**，装好自己填。

## 开发

```
lib/index.js    host 半边：配置读写、表情目录扫描、HTTP 路由（/x-kuakua/*）
lib/client.js   页面半边：按钮、面板、右键菜单、设置页
locale/         插件在 Plugin Manager 里显示的名字和介绍
```

改完 `lib/*.js`：页面那半边热更新；host 半边要让插件重新加载（关一下再开这个插件，或重启 dsh）。
